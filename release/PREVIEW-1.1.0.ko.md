비전 어시스트 1.1.0 테스트 버전

폴더에서 엑셀과 사진/PDF를 골라 준비하고, 실적 입력 또는 가공식품 신규 입력을 시작할 수 있습니다. 신규 입력은 여러 품목·표시사항·제조공정·주/부성분·첨부·오류검증까지 연결했습니다. 중단 후 이어하기는 이미 입력된 행을 확인해 중복 추가를 막습니다.

설치:
1. 아래 `VisionAssist-1.1.0-setup.exe`를 내려받아 실행합니다.
2. 기존 비전 프로그램을 선택하고 `연결 준비`를 누릅니다.
3. 열린 Chrome 확장 관리에서 비전 카드의 새로고침(↻)을 누르고 `연결 확인하고 시작`을 누릅니다.

기존 자료와 확장 연결을 유지합니다. 다음 실행은 바탕화면 비전 어시스트를 사용합니다. 이 버전은 테스트용이므로 기존 앱의 최신 업데이트 버튼 대신 위 설치 파일로 적용합니다.

앱에서 `양식 받기`와 `GPT 정리 지침`을 받을 수 있습니다. GPT로 정리한 엑셀을 넣거나 직접 입력하고, 시작 전에 사진을 선택하세요. 앱에 AI API 키는 필요하지 않습니다. 원본 인보이스/PDF를 앱 자체가 해석하는 기능은 아닙니다.

검증: 실제 Chrome 확장에서 합성 신고서 화면으로 전체 신규 흐름, 앱 재개, 성분 순번 변경, 원본 첨부 보존, 안내창 처리를 검사했습니다. Windows 빌드와 업데이트 복구 검사도 통과한 파일입니다.

실제 UNI-PASS 신규 화면의 전체 입력·저장·전송 검증은 아직 하지 못했습니다. 실제 화면의 조회칸이 다르면 해당 단계에서 멈추고 진행 기록을 남깁니다. 가공식품 신규 입력을 대상으로 하는 테스트 버전이며, 안정 버전 v1.0.11은 유지합니다. 신규 전송은 UNI-PASS에서 직접 누릅니다.
