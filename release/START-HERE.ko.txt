비전 어시스트 1.2.0

기존 사용자: 앱에서 업데이트 확인 → 업데이트 설치 → 새 버전으로 다시 열기.
기존 자료는 유지됩니다. 확장을 삭제하거나 다시 등록할 필요가 없습니다.

처음 한 번:
1. 오른쪽 위 설정 → 회사·화주·제품 기본정보 관리에서 회사 연락처와 번호 저장.
2. 준비한 작업을 불러와 ‘현재 자료를 제품으로 저장’하거나 제품 등록에서 엑셀/직접 입력.
3. 기본정보 관리의 백업 받기로 자료 보관.

평소 사용:
1. 실적 기반 입력 또는 신규 입력에서 저장한 화주와 제품 선택.
2. 이번 선적 폴더 선택, 화물번호·선적일·수량·중량·가격·제품 날짜 입력.
   수량·중량·가격이 같으면 저장한 값 적용 버튼 사용.
3. 한글표시 사진 → 제품 전면 → 기타 서류를 클릭해 선택.
4. 입력 시작. 중단되면 원래 유니패스 탭을 유지한 채 진행 기록 확인.
5. 오류검증과 내용을 검토한 뒤 최종 전송.

다음 건 준비는 고정정보만 유지하고 화물·날짜·사진을 비웁니다.
작성 중인 자료는 자동 저장되며 다음 실행 때 이어서 준비할 수 있습니다.
현재 자동 신규 입력 범위는 가공식품입니다. 실제 UNI-PASS 신규 전체 실행은 현장 확인이 필요합니다.
