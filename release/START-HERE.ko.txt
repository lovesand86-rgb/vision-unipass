비전 어시스트 1.3.0

기존 앱: 업데이트 확인 → 업데이트 설치 → 새 버전으로 다시 열기.

처음 한 번: 첫 화면에 신청인 전화번호를 저장합니다.
대행업체 번호는 기본값으로 준비되어 있습니다.
유니패스에 표시된 신청인 이름·주소·이메일·휴대폰은 유지합니다.
휴대폰을 바꿔야 할 때만 추가 정보에서 지정합니다. 화주 알림번호는 별도입니다.

매번 신고할 때:
1. 앱에서 신고자료 양식과 GPT 정리 지침을 받습니다. 이미 양식이 있으면 다시 받을 필요 없습니다.
2. 인보이스·패킹·제품자료로 완성한 엑셀을 ‘비전-신고자료.xlsx’라는 이름으로 사진과 같은 폴더에 넣습니다.
3. 실적 기반 입력 → 새로 시작 → 폴더 선택.
4. 자동으로 읽힌 요약 아래에서 한글표시 사진 → 제품 전면 → 기타 서류를 선택하고 입력 시작.
5. 유니패스에 입력된 내용과 오류검증 결과를 보고 최종 전송합니다.

엑셀에 화주·제품·이번 선적을 넣으면 따로 등록하거나 재입력할 필요 없습니다.
실적접수번호 또는 실적신청번호를 넣으면 그 건을 조회합니다.
오래된 실적은 실적신청일도 넣으세요. 번호가 없으면 동일 제품 최신 실적을 찾습니다.

필요할 때만 ‘자료 보기·직접 입력’을 열어 수정하거나 저장한 정보를 사용하세요.
자료가 부족하면 빠진 항목을 알려줍니다. 진행 자료는 자동 저장되며 ‘작업 이어하기’로 다시 엽니다.
현재 실적 복사는 단일 품목, 신규 자동 입력은 가공식품 범위입니다.
