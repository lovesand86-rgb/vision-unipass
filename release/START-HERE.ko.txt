비전 어시스트 1.0.6 — 검토용 실행 파일

기존 사용자: 앱의 업데이트 확인에서 1.0.6을 설치하고 새 버전으로 다시 여세요. 기존 도구 탭은 먼저 닫아주세요.

1. 처음 설치할 때 VisionAssist-1.0.6-win-x64.exe를 실행하세요.
2. 처음 한 번만 기존 확장과 연결합니다.
   기존 비전 도구 탭은 닫고, UNI-PASS 화면은 그대로 두세요.
   프로그램이 찾은 기존 Chrome 프로필·확장 폴더를 선택합니다.
   안내에 따라 Chrome 확장을 한 번 새로고침하고 새 권한을 확인합니다.
3. 이후 바탕화면 ‘비전 어시스트’만 누르면 됩니다.

메뉴
실적 기반 입력 / 신규 자료 입력 / 작업 이어하기 / 업데이트 확인
설정은 오른쪽 위 톱니바퀴에 있습니다.

신규 자료는 엑셀의 ‘항목 / 값 / 출처’ 세 열로 붙여넣을 수 있습니다.
원문 확인 체크 → 작업 저장 → 입력칸 연결 → 미리보기 → 입력 순서입니다.
자료 저장은 UNI-PASS 저장과 다릅니다.
처음 사용하는 화면에서는 실제 입력칸을 연결해야 합니다.
표의 행 추가·코드 조회·기관별 업무규칙까지 자동 처리하는 단계는 아닙니다.

업데이트 서버에 새 버전이 게시되면 프로그램에서 받을 수 있습니다.
업데이트는 GitHub의 vision-unipass 릴리스에서 배포합니다.
서버에 버전이 없다는 안내는 현재 프로그램을 사용할 수 없다는 뜻이 아닙니다.

보관
설정의 ‘작업 백업’으로 자료를 보관할 수 있습니다.
기존 확장을 삭제하지 마세요. 확장 제거는 Chrome에 저장한 작업 자료를 지울 수 있습니다.

검증 범위
Windows 실행 파일 빌드와 Linux의 실제 브라우저·합성 입력·업데이트 복구 검증은 마쳤습니다.
실제 Windows 첫 연결과 회사 UNI-PASS 화면의 동작은 마지막 PC 확인 대상입니다.
