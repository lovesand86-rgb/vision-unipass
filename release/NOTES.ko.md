비전 어시스트 1.0.6 — 한 번에 입력, 간편한 사진 첨부

기존 품목을 대조한 뒤 확인 체크를 반복하던 화면을 줄였습니다. 입력 시작 한 번으로 현재값을 읽고, 같은 신청서·품목의 미반영 값은 제한된 복구 절차로 이어서 입력합니다. 값이 이미 맞으면 다시 수정하지 않습니다. 다른 화물이나 신청서, 확인할 수 없는 화면에서는 멈춥니다.

- 화물관리번호 조회창의 실제 경로 `myc/comm`을 인식하도록 주소 오타 수정. 같은 신청서에서 열린 조회창은 재사용합니다.
- 사진을 큰 영역에 드래그하거나 클릭해 여러 장 선택. 파일명으로 한글표시/전면을 구분할 수 있으면 자동 배치하고, 모호한 사진은 미리보기에서 지정합니다. 기타 사진 순서는 화살표로 변경합니다.
- 입력 결과·상세 기록·저장·전송은 접어두고, 입력 후 유니패스에서 검토할 수 있도록 정리했습니다.
- 현재 신청인에게 이미 입력된 유효한 연락처는 재확인 없이 사용합니다. 누락된 연락처만 입력받습니다.
- 전용 앱 창은 홈 약 460×560, 작업 화면 620×740으로 조정합니다. 화면 해상도에 맞춰 제한하며 일반 Chrome 창은 바꾸지 않습니다. 기존 실행기에서도 확장 업데이트로 적용됩니다.
- 검색 완료 후 다음 입력 화면으로 넘어갈 때 불필요한 종료 확인창이 뜨지 않도록 수정했습니다.
- 진행 기록에 앱 버전과 관련 팝업 경로를 추가했습니다.

**적용:** 자동입력이 끝난 상태에서 앱의 업데이트 확인 → 업데이트 설치 → 새 버전으로 다시 열기. 기존 UNI-PASS 작성 화면은 유지하고, 새로 복사하지 말고 이어서 입력하세요.

입력 시작은 입력·사진 첨부까지 처리합니다. 최종 저장·전송은 별도 버튼입니다. 사진 원본은 작업창을 닫으면 다시 선택해야 합니다. 인증서·사진·작업 내용을 공개 서버로 업로드하지 않습니다.

검증: 임시 Chrome과 합성 UNI-PASS에서 한 번 시작으로 품목 복구·화물 조회·입력 진행, 다른 대상 차단, 실제 DOM 교체 후 결과 읽기, 사진 드래그·역할·순서, 작은 화면 및 일반 Chrome 창 보존을 확인했습니다. 기본 UI/자료 모델/화면 이동/창고 조회 검사도 통과했습니다. Windows 빌드와 업데이트 복구 검사는 릴리스에서 실행합니다. 실제 로그인된 회사 업무 화면의 최종 동작은 현장 확인이 필요합니다.
