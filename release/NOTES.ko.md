비전 어시스트 1.0.8 — 열린 화물 조회창 인식 수정

1.0.7에서 화물관리번호 조회창은 열리지만 H B/L과 연도를 입력하지 못하고 멈추던 문제를 수정했습니다. 실제 진행 기록의 주소는 `/csp/myc/comn/ComnCdCtr/openMYC0801008Q.do`입니다. 앞선 버전에서 화면 이미지로 잘못 판독했던 주소를 이 기록의 정확한 주소로 교체했습니다.

열린 창이 현재 신청서에 속하는지 확인한 뒤 기존 창에서 조회를 이어갑니다. 제품·화주·제조업소 및 조회 결과의 화물번호·M B/L·H B/L 확인은 유지합니다. 화물번호를 직접 덮어쓰거나 확인 없이 화물을 선택하지 않습니다.

적용: 앱에서 업데이트 확인 → 설치 → 새 버전으로 다시 열기. 제목의 v1.0.8을 확인하고 실적 기반 입력 → 이어서 입력으로 기존 신청서에서 재개하세요. 첨부 파일은 다시 선택해주세요. 새로 복사할 필요는 없습니다. 저장·전송은 별도입니다.

검증: 진행 기록에서 옮긴 실제 경로와 창 연결 관계를 테스트 자료로 사용했습니다. 격리 Chrome에서 기존 팝업 인식·재사용, 중단 기록 이어하기, 실제 주입 함수의 H B/L·연도 입력과 조회 버튼 1회 실행을 확인했습니다. 합성 화면 검사이며 실제 업무 사이트의 조회 결과 선택과 최종 입력은 현장 확인이 남아 있습니다.
