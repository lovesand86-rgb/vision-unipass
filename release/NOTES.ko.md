비전 어시스트 1.0.11 — 사진은 처음에, 시작은 한 번

작업 준비 화면에서 한글표시사항·제품 전면·기타 사진/PDF를 먼저 선택합니다. 시작하기를 누르면 실적 확인·복사 후 같은 창에서 입력과 첨부, 오류검증까지 이어갑니다. 중간 화면에서 첨부를 다시 선택하거나 시작 버튼을 다시 누르지 않아도 됩니다.

- 선택한 원본 파일과 분류·순서를 같은 PC의 다음 작업 화면으로 전달합니다. 전달받은 임시 자료는 삭제합니다. 다른 작업·다른 앱 창·사용한 연결 정보로 자동 입력하지 않습니다.
- 다음 건 준비에서는 이전 사진을 비우고 준비 화면으로 돌아갑니다. 이전 사진으로 바로 새 복사를 진행하지 않습니다.
- 실제 UNI-PASS 문구 ‘오류검증 결과 오류가 존재하지 않습니다.’를 검증 성공으로 인식하고 확인 안내를 닫습니다. 다른 오류나 추가 안내를 무조건 넘기지 않습니다.
- 오류검증 통과 후 전송 준비 완료 화면은 유지합니다. 실제 전송은 사용자가 마지막 전송 버튼을 눌렀을 때 진행합니다.

기존 앱의 업데이트 확인 → 설치 → 새 버전으로 다시 열기. 창 제목의 v1.0.11을 확인하세요. 이미 입력과 첨부가 완료된 건을 새로 복사할 필요는 없습니다.

검증: 격리 Chrome에서 첫 화면 파일 선택부터 실제 앱 내 화면 전환·원본 유지·자동 입력 진입, 다른 작업 차단, 전달 정보 재사용/만료 차단 및 임시 자료 삭제를 검사했습니다. 보고된 오류검증 문구의 실제 알림 처리, 기존 입력·첨부·화면 이동·다음 건 준비 검사도 통과했습니다. 실제 업무 신고서를 저장하거나 전송하지 않았습니다.
