비전 어시스트 1.0.2 — 버튼 중심의 간단한 화면

앱에서 **업데이트 확인 → 새 버전 확인 → 업데이트 설치 → 새 버전으로 다시 열기**를 선택하세요. 실행 파일을 다시 받을 필요는 없습니다.

- 실적 메뉴: **새로 시작 / 이어서 입력** 두 가지 큰 버튼
- 실적 불러오기: 작업 대상 확인 후 **시작하기**
- 파일 변경, 수동 확인, 작업 정리, 진행 기록은 펼쳐서 사용
- 여러 UNI-PASS 화면이 열려 있을 때만 대상 선택 표시

기존 입력·검증·저장·전송 조건은 유지합니다. 복사 결과가 불확실한 작업은 다시 복사하지 않고 결과만 확인합니다. 신규 설치용 EXE도 함께 제공합니다.

임시 Chrome 환경에서 화면 이동, 단일 시작 버튼, 파일로 가져온 작업, 여러 대상 선택, 불명확한 복사 결과의 재복사 방지를 확인했습니다. UNI-PASS 동작은 합성 화면과 실행 응답으로 검사했으며 실제 업무 건을 전송하지 않았습니다.
