비전 어시스트 1.0.9 — 첨부파일 안내 확인 처리

첨부파일 탭의 정상 안내창에 있는 닫기 아이콘의 영문 close를 안내 본문으로 읽어 사진 첨부 직전에 중단하던 문제를 수정했습니다. 알려진 안내 내용을 확인한 뒤 확인 버튼을 한 번 누르고 첨부를 이어갑니다.

- close는 닫기 버튼 안에 있는 경우에만 본문 판독에서 제외합니다. 다른 안내 문구를 무조건 넘기지 않습니다.
- 오늘 하루 그만보기의 체크 상태를 바꾸지 않습니다. 사용자가 이미 선택한 상태도 유지하며, 안내창이 없는 경우는 바로 진행합니다.
- 확인 후 창이 닫히지 않으면 반복해서 누르지 않습니다. 신청서 대상 검사도 유지합니다.

기존 앱에서 업데이트 확인 → 설치 → 새 버전으로 다시 열기. 제목의 v1.0.9를 확인하고 기존 신청서에서 이어서 입력으로 진행하세요. 첨부 파일은 다시 선택해야 합니다. 새로 복사할 필요는 없습니다. 저장·전송은 별도입니다.

검증: 격리 Chrome에서 보고된 안내문과 close 아이콘을 재현해 확인 1회 실행, 체크 상태 보존, 안내창 미표시, 다른 안내 문구 및 대상 변경 차단, 중복 클릭 방지를 확인했습니다. 실제 업무 화면의 파일 첨부 완료는 현장 확인이 필요합니다.
