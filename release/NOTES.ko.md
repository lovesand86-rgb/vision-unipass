비전 어시스트 1.0.1 — 작업 화면 통합

기존 사용자는 실행 파일을 다시 내려받지 않아도 됩니다. 열린 기존 비전 도구 탭을 닫고 **비전 어시스트 → 업데이트 확인 → 새 버전 확인 → 업데이트 설치 → 새 버전으로 다시 열기**를 선택하세요. UNI-PASS 화면은 그대로 두세요.

실적 검색, 품목·화물 입력, 공통사항, 상세 도구가 비전 어시스트의 같은 창에서 전환됩니다. 작업 화면에 홈·설정·실적 메뉴를 추가하고 디자인을 통일했습니다. 상세 도구에서 UNI-PASS가 여러 개 열려 있으면 대상을 직접 선택하며, 미리보기 후 입력은 동일한 대상으로 유지합니다. 실행 중인 작업의 화면 이동을 막고 파일·입력 내용을 남겨둔 채 이동할 때 확인합니다.

Chrome의 UNI-PASS 로그인·입력 화면은 계속 필요합니다. 기존 개인 작업 설정, 연락처, 저장 자료는 유지합니다. 새 기능이나 실제 기관 제출 자동화는 추가하지 않았습니다.

임시 Chrome 확장 환경에서 같은 탭 유지·화면 선택·취소·작업 중 이동 차단 및 기존 UI/합성 입력 검사를 수행했습니다. 대상 선택 검사는 사이트 권한을 미리 부여한 격리된 복사본과 합성 UNI-PASS 페이지로 검사했습니다. 실제 회사 PC의 Chrome 앱 창 및 UNI-PASS 통합 동작은 별도 확인이 필요합니다.

처음 설치하는 경우 **VisionAssist-1.0.1-win-x64.exe**를 실행하고 연결 안내를 따르세요. update.json과 vision-extension-core.zip은 앱 업데이트용입니다.
