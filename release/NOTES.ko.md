비전 어시스트 1.2.0 — 저장한 제품을 고르고 이번 선적만 입력

회사·화주·제품 정보를 PC에 저장해 매번 전체 엑셀을 작성할 필요를 줄였습니다. 평소에는 화주와 제품 선택 → 이번 선적의 변경값 입력 → 사진 선택 → 입력 시작 순서로 사용합니다.

- 회사: 대행업체 번호와 신청인 연락처, 기본 문자 수신번호.
- 화주: 사업자·허가번호, 연락처, 자주 쓰는 신고기관·검사장소.
- 제품: 제조업소, 제품명·규격·단위, 유형, 성분·배합비, 제조공정, 고정 표시사항. 기존에 작성한 작업도 ‘현재 자료를 제품으로 저장’으로 등록합니다.
- 수량·중량·USD 가격은 저장한 값을 각각 또는 한 번에 적용합니다. 값은 준비 기록이며 유니패스 전송 실적이라고 표시하지 않습니다.
- 새 작업에는 이전 화물번호·날짜·사진을 가져오지 않습니다. 날짜 표시사항은 이번 제조일자/소비기한으로 채우고, 품목마다 날짜가 다르면 직접 입력합니다.
- 작성 중인 자료와 선택한 원본 첨부는 자동 저장합니다. 다시 열면 ‘이어서 준비’로 복원합니다.
- 기본정보 관리에서 수정·제품 삭제·백업 내보내기/가져오기를 제공합니다. 폴더의 엑셀은 목록에서 선택했을 때만 읽습니다.

기존 사용자는 앱의 업데이트 확인 → 업데이트 설치 → 새 버전으로 다시 열기를 사용하세요. 이번 버전은 별도 설치 파일을 다시 받을 필요가 없습니다. 기존 Chrome 프로필의 자료와 확장 연결은 유지됩니다.

처음 한 번 회사 정보를 저장하고 화주·제품을 등록하세요. 이미 준비한 작업이나 엑셀이 있으면 불러와 저장하면 됩니다. 이후 전체 엑셀 작성은 선택 사항입니다.

검증: Node 모델 검사, 실제 확장 브라우저의 준비 자료→제품 등록→새 선적→값 적용→자동 저장/복원→다음 건/사진 초기화→백업 검사, 기존 폴더·신규 입력 흐름 및 Windows 빌드/업데이트 복구 검사. 신규 가공식품 자동 입력은 기존 1.1.0과 같은 범위이며 실제 UNI-PASS 신규 신고 전체 완료를 검증한 것은 아닙니다. 최종 전송은 사용자가 검토 후 수행합니다.
