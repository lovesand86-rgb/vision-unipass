비전 어시스트 1.0.4 — 식약보관창고 조회창 인식 수정

식약보관창고 조회창이 열렸는데도 도구가 찾지 못해 창고코드 입력 전에 멈추는 오류를 수정했습니다. 실제 조회창 경로의 `infomt`를 `informt`로 잘못 판별하던 두 곳을 바로잡았습니다.

앱에서 **업데이트 확인 → 새 버전 확인 → 업데이트 설치 → 새 버전으로 다시 열기**를 선택하세요. 기존 UNI-PASS 작성 화면은 그대로 두고, 진행 중인 자동입력이 멈춘 상태에서 업데이트하세요.

이미 품목·공통사항 입력을 마친 건은 기존 작성 화면에서 **창고·신고기관·제품상태만 다시 확인**을 한 번 실행하세요. 실적 검색·복사를 처음부터 반복할 필요가 없습니다.

검증: 격리된 Chrome 합성 화면에서 별도 탭 탐색, 창고코드 입력·조회·기관명 읽기, 중복 조회 방지, 다른 신청서·잘못된 조회창 차단을 확인했습니다. Windows 빌드 및 기존 자료 모델·업데이트 복구 검증은 릴리스 작업에서 실행합니다. 실제 로그인된 회사 업무 화면에서의 최종 동작은 업데이트 후 확인이 필요합니다. 임시저장·전송 동작은 변경하지 않았습니다.
