비전 어시스트 1.0.7 — 고정 첨부칸과 간편한 다음 작업

- 첫 화면과 작업 화면의 프로그램 이름 아래, 창 제목에 현재 버전을 표시합니다.
- 한글표시사항 1개 / 제품 전면 1개 / 기타 사진·서류 최대 9개로 첨부칸을 고정했습니다. 각 칸에 드래그하거나 클릭해 선택합니다. 이미지와 PDF를 지원하며 엑셀·워드는 받지 않습니다. 파일당 5MB 제한입니다.
- 복사 후에는 첨부 파일을 준비할 수 있도록 기다립니다. 입력 시작·이어하기를 누르면 진행합니다.
- 화물 조회창의 CommCdCtr 경로를 인식하도록 보완했습니다. 기존 ComnCdCtr 경로도 지원하며 대상·화물 일치 검사는 유지합니다.
- 체크박스로 닫은 작업을 확인하던 절차를 다음 건 시작 버튼으로 바꿨습니다. 열린 신청서가 없는지 검사하고 이전 기록을 보관한 뒤 다음 작업을 시작합니다. 작성 중인 신청서를 자동으로 닫거나 삭제하지 않습니다.
- 진행 기록에 인식되지 않은 다른 UNI-PASS 창의 경로도 남겨 팝업 오류를 확인할 수 있게 했습니다. 주소의 검색 조건은 기록하지 않습니다.

기존 앱에서 업데이트 확인 → 설치 → 새 버전으로 다시 열기를 누르세요. 입력 중인 작업이 있다면 먼저 작업이 멈춘 것을 확인하고 앱 도구 화면을 닫은 뒤 업데이트하세요. UNI-PASS 작성 화면은 유지합니다.

검증: 격리 Chrome의 합성 화면에서 화물 창 탐색, 품목 입력 복구, 고정 첨부칸·PDF 원본 전달·엑셀 거부, 다음 작업의 열린 신청서 보호와 기록 보관, 화면 이동을 검사했습니다. 실제 로그인된 UNI-PASS에서의 최종 동작은 현장 확인이 필요합니다. 저장·전송은 별도입니다.
