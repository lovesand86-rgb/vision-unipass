비전 어시스트 1.0.5 — 업데이트 재시작 후 빈 창 방지

업데이트 후 새 버전으로 다시 열 때, 기존 비전 어시스트 창이 빈 크롬 창으로 남는 문제를 수정했습니다. 재시작 요청이 정상 접수되면 해당 앱 화면을 먼저 닫고 확장을 다시 불러옵니다. 재시작 연속 클릭으로 실행기가 여러 번 호출되는 것도 막았습니다.

유니패스와 일반 크롬 탭은 닫지 않습니다. 다른 비전 입력 도구가 열려 있거나 미확인 입력 기록이 있으면 업데이트·재시작을 중단합니다. 별도 탭 읽기 권한을 추가하지 않고 확장 자체 화면 목록으로 이를 확인합니다.

앱에서 **업데이트 확인 → 새 버전 확인 → 업데이트 설치 → 새 버전으로 다시 열기**를 선택하세요. 1.0.4 이하에서 이번 버전으로 넘어오는 최초 재시작은 이전 코드가 실행되므로 빈 창이 한 번 더 남을 수 있습니다. 그 빈 창은 직접 닫아주세요. 홈 하단 버전이 1.0.5로 바뀐 뒤부터 수정된 재시작 방식이 적용됩니다. 이미 남은 일반 크롬 창은 사용자의 새 탭과 구분할 수 없어 자동으로 닫지 않습니다.

검증: 격리된 Chrome에서 기존 빈 창 현상을 재현하고, 수정 후 실제 확장 재시작 두 회에서 기존 앱 창 제거·유니패스와 사용자 새 탭 보존·중복 재시작 방지를 확인했습니다. 실행기 실패 시 현재 창 유지, 다른 입력 도구/미확인 작업이 있을 때 차단도 검사했습니다. 네이티브 실행기의 새 창 열기는 테스트 대체 기능을 사용했으며, 실제 Windows PC에서의 마지막 확인은 필요합니다. 1.0.4의 창고 조회창 주소 수정도 포함합니다.
