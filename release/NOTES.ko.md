비전 어시스트 1.3.0 — 폴더 선택으로 신고자료와 사진 준비

엑셀에 있는 화주·제품·이번 선적을 프로그램에서 다시 고르거나 입력하던 단계를 줄였습니다. 폴더 안의 ‘비전-신고자료.xlsx’를 자동으로 읽고 요약과 사진 선택을 보여줍니다. 제품을 미리 등록하지 않아도 됩니다.

- 대행업체 사업자번호와 허가번호는 요청한 기본값으로 준비했습니다. 기존에 저장한 회사 값은 유지합니다.
- 첫 화면에서 신청인 전화번호 하나만 저장하고, 이후 수정할 수 있습니다. 신청인 이름·주소·이메일은 현재 유니패스 정보를 사용합니다. 휴대폰을 별도로 지정하지 않으면 현재 값을 유지합니다. 화주 알림번호는 별도로 관리합니다.
- 정해진 파일명은 비전-신고자료.xlsx입니다. 다른 엑셀은 자동으로 읽지 않으며, 같은 이름이 여러 개면 선택합니다. 폴더가 바뀌면 이전 선적·사진 선택을 초기화합니다.
- 엑셀의 사업자번호로 저장된 화주를 연결하고, 이번 자료의 값이 우선합니다. 처음 읽은 화주·제품도 자동으로 기록합니다. 폴더명이나 사진으로 화주를 추측하지 않습니다.
- 실적접수번호 또는 실적신청번호로 조회할 수 있습니다. 실적신청일을 넣으면 그 날짜를 조회합니다. 번호가 없으면 3개월 → 1년 → 3년 동일 실적 검색을 사용합니다. 지정한 실적과 대상이 다르면 다른 건으로 대체하지 않습니다.
- 엑셀에서 읽은 내용을 다시 입력하거나 항목별 확인할 필요가 없습니다. 빠진 필수정보만 알리고, 직접 수정은 ‘자료 보기·직접 입력’에서 가능합니다. 선택한 사진과 작업은 자동 저장합니다.

사용: 앱에서 업데이트 확인 → 업데이트 설치 → 새 버전으로 다시 열기. 새 설치 파일을 받을 필요가 없습니다. 양식 받기로 새 엑셀과 GPT 정리 지침을 받을 수 있습니다. 기존 양식도 계속 읽을 수 있으며 실적번호 항목은 선택 사항입니다.

검증: 모델 검사, 실제 Chrome 확장에서 폴더/엑셀 자동 읽기·연락처·사진·복원·파일 오류, 실적번호 일치 검사, 기존 신규 입력 흐름, Windows 빌드/업데이트 복구. 실사이트의 신규 신고 전체 실행은 현장 확인이 남아 있습니다. 현재 실적 복사는 단일 품목, 신규 자동 입력은 가공식품 범위이며 최종 전송은 사용자가 합니다. 업무시스템 거래처 사이트와 직접 연결하는 기능은 이번 변경에 포함하지 않았습니다.
