비전 어시스트 1.0.3 — 원문 열기 오류와 재시도 수정

앱에서 **업데이트 확인 → 새 버전 확인 → 업데이트 설치 → 새 버전으로 다시 열기**를 선택하세요. UNI-PASS 원문 창은 그대로 두세요.

- 주소를 아직 읽을 수 없는 탭 때문에 원문 찾기가 중단되던 Invalid URL 오류 수정
- 원문을 연 뒤 중단된 작업은 검색을 반복하지 않고, 일치하는 열린 원문부터 재개
- 복사 요청 기록이 있으면 기존처럼 결과만 확인하며 재복사하지 않음
- 조회 조건의 숨겨진 중복 요소를 구분하고, 조건이 없거나 활성 화면이 여러 개이면 입력 전에 중단
- 아직 복사 전인 작업의 결과 확인 안내를 쉽게 수정

업데이트 후 실적 불러오기에서 **시작하기**를 한 번 누르세요. 같은 실적 원문이 여러 개 열려 있다는 안내가 나오면 하나만 남겨주세요. 원문을 확인할 수 없다는 안내가 나오면 UNI-PASS에서 해당 실적의 원문보기를 연 뒤 이어갈 수 있습니다.

격리된 Chrome과 합성 화면에서 URL 누락·원문 로딩·응답 유실·이전 버전 기록 복구·중복 복사 방지·조회 조건 누락/중복을 검증했습니다. 실제 업무 건을 복사하거나 전송하지 않았으며 실제 회사 UNI-PASS 화면 확인은 별도로 필요합니다.
