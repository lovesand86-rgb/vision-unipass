비전 어시스트 1.0.10 — 오류검증까지 자동으로, 마지막은 전송 버튼

입력·사진 첨부가 완료되면 최종 내용을 읽고 오류검증을 자동 실행합니다. 같은 내용의 확인된 검증 결과가 있으면 반복하지 않습니다. 검증 통과 후에는 첨부 화면을 접고 전송 준비 완료와 큰 전송 버튼을 표시합니다.

전송은 사용자가 전송 버튼을 눌렀을 때 실행합니다. 필요한 임시저장은 그때 먼저 진행하고 성공 안내 및 신청번호를 확인한 뒤 전송합니다. 준비 단계에서 자동 저장·전송하지 않습니다. 사이트 자체의 추가 확인창이 나오면 유니패스에서 확인해주세요.

오류검증 실패·결과 미확인·입력 또는 첨부 미완료 상태는 준비 완료로 표시하지 않습니다. 검증 후 신고서 내용이 바뀌면 저장·전송 전에 멈추고 재검증하도록 안내합니다. 내용 수정·다시 검증에서 수정과 재검증을 이어갈 수 있습니다. 새 파일을 선택한 경우에는 먼저 입력·첨부를 반영해야 합니다.

적용: 기존 앱의 업데이트 확인 → 설치 → 새 버전으로 다시 열기. 제목의 v1.0.10 확인. 새 작업은 입력 시작 후 오류검증까지 진행됩니다. 기존 작성 건은 이어서 입력으로 진행하고, 필요한 첨부 파일을 다시 선택하세요.

검증: 격리 Chrome의 합성 UNI-PASS에서 실제 최종 입력 읽기·버튼 실행·브라우저 결과 알림 처리를 사용해 자동 검증, 명시적 전송 클릭 후 저장→전송, 검증 오류/미확인, 내용 변경, 저장 실패, 재전송 차단을 검사했습니다. 전체 입력 흐름과 준비 완료 화면 연결 및 기존 화물·첨부 회귀 검사도 통과했습니다. 실제 업무 신고서를 저장하거나 전송하지 않았으며 새 최종 흐름의 현장 확인은 남아 있습니다.
