처음 쓰는 담당자 연락처 확인










창고·신고기관·제품상태




신고기관은 이번 창고 조회 결과에서 읽습니다. 창고명이나 이전 신고기관으로 추정하지 않습니다.



화물 반입 이력을 조회해 창고를 확인합니다. 품목·날짜·연락처와 사진은 다시 입력하지 않습니다.


제품상태 확인 기준









이번 제품 사진


선택한 사진을 신고서에 첨부합니다. 한글표시 내용은 사람이 직접 대조·수정합니다.


원본을 선택하면 아래 슬롯에 넣고 파일명·크기·해시를 확인합니다. 저장·접수 완료를 뜻하지 않습니다.












오류검증·임시저장·전송


입력과 사진 첨부를 마친 뒤 사용하세요. 한글표시사항은 직접 대조·수정해 주세요.






오류가 나오면 해당 입력을 수정한 뒤 ‘최종 입력내용 읽기’를 다시 누르세요. 한 건씩 재검증하며 오류가 없을 때 저장합니다.




최종 입력내용을 먼저 읽어 주세요.




결과를 자동 확인하지 못한 경우

유니패스에서 실행 결과를 직접 확인한 뒤 기록하세요.









아래 버튼은 실제 신고서를 전송합니다. 현재 내용의 오류검증과 임시저장 결과가 확인되어야 실행할 수 있습니다. 전송 후 접수·수리 상태는 유니패스 처리현황에서 확인하세요.
