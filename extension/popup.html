UNI-PASS 입력칸 확인

화면 구조 확인과 신고서 입력을 돕습니다. 통합 입력 도구의 최종 단계에서 오류검증·임시저장을 실행하며 전송은 별도 버튼으로 실행합니다.

아이콘 없는 원문보기 창 읽기

원문보기 창을 열어둔 채 일반 크롬 창에서 사용하세요. 처음 찾을 때 UNI-PASS 사이트 접근 권한을 요청합니다. 선택한 창의 구조만 읽으며 신고값을 입력하지 않습니다.

    어떤 정보를 읽나요?

    입력칸 ID·이름·종류, 항목 이름, 버튼 문구, 화면 경로를 읽습니다. 입력값·첨부파일·쿠키·비밀번호는 읽지 않습니다. 선택목록의 내용도 제외합니다.

    자동 업로드는 없습니다. 저장된 JSON을 확인한 뒤 대화에 첨부해 주세요. 항목 이름이나 버튼 문구 자체에 업무정보가 있으면 포함될 수 있습니다.

    신고값 입력 시험 · 준비된 작업 파일 필요

    이번 화물 연결 후 채번 전 복사본에서만 사용합니다. 품목 입력 시험은 품목사항 탭에서 해당 품목을 먼저 선택하세요.

    작업 파일에 있는 수량·중량·금액·날짜·담당자 연락처 중 해당 탭의 항목만 입력합니다. 제조공정·성분·한글표시·첨부·저장·전송은 처리하지 않습니다.

    이 단계는 현재 입력값을 읽어 위에 비교 표시합니다. 해당 값과 작업 파일은 확장 저장소나 외부로 보내지 않습니다. 창을 닫으면 작업 파일을 다시 선택해야 합니다.
