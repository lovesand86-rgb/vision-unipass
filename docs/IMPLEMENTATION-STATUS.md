# 비전 어시스트 1.1.0 테스트 버전

폴더·엑셀 준비 화면을 실적 입력과 신규 입력에 연결했다. 신규 버튼은 이제 읽기 전용 진단이 아니라 실제 입력 실행/이어하기다. 자료 읽기는 PC 내부의 전용 XLSX 파서이며, AI API 호출이나 인보이스/PDF 내용 자동 추론은 없다.

## 사용 흐름

1. 폴더 선택 → 전용 엑셀 읽기 또는 직접 입력. 기본 연락처·대행업체 번호는 설정에서 저장한다.
2. 사진/PDF에서 한글표시, 제품 전면, 기타를 선택한다. 전면에는 사진만 허용한다.
3. 실적 입력은 동일 제품/화주/제조업소를 최근 3개월 → 1년 → 3년에서 찾아 단일 품목의 기존 흐름으로 연결한다. 이전 수량·중량·USD 가격은 각 항목 또는 세 항목을 적용할 수 있다.
4. 신규 입력은 빈 신청서에서 공통정보 → 화물조회/여러 품목 → 신고일반 → 제품유형 → 한글표시 → 공정 → 성분 → 미리 고른 첨부 → 오류검증 순으로 진행한다.
5. 신규의 실제 전송은 UNI-PASS에서 사용자가 누른다. 파이프라인은 전송을 자동 요청하지 않는다.

## 신규 구현

- 가공식품 1차 지원. 제품구분 변경은 빈 신청서에서만 수행한다. 알려진 초기화 안내만 확인하며, 다른 문구는 화면에 남긴다.
- 사업자/허가/제조업소/창고/검사기관, 용도/국가/항구, 단위 조회. 관측된 ID 또는 유일한 정확한 화면 라벨로 입력칸을 찾는다. 조회창은 같은 신청서·조회 대상에 연결하고 코드/명칭을 대조한다.
- 화물 조회는 HBL/연도를 입력하고 화물번호·MBL·HBL을 대조한 뒤 선택한다. 품목 추가 후 제품명·한글명·화물번호·수량·중량·가격·날짜를 목록에서 확인한다.
- 여러 품목은 제조일자가 빠른 품목을 대표로 정한다. 제조일자를 모르면 사용자가 대표품목 한 건을 지정한다. 소비기한 종료일을 제조일자로 추정하지 않는다. 총수량 단위는 별도로 조회한다.
- 제품유형·표시사항 여러 행, 순서대로 공정 선택 후 실제 추가, 주/부/혼합 성분 등록을 연결했다. 성분 상하위 관계는 실제 순번을 다시 읽으며 배열 위치를 부모 순번으로 사용하지 않는다.
- 하위 성분이 여러 개인 원료의 제품구분·품목유형 입력을 지원한다. 부성분 비율은 상위성분 기준 자료만 받으며 임의로 환산하지 않는다.
- 안내창은 textarea 본문도 읽고 알려진 전체 문구를 확인한다. 오늘 하루 그만보기 설정은 유지한다.
- 첨부 원본을 분할 전달하고 이름/크기/SHA-256으로 확인한다. PDF를 제품 전면 위치에 넣지 않는다.
- 입력 의도를 Chrome 저장소에 먼저 기록한다. 응답이 유실되면 목록의 반영 결과를 읽는다. 결과가 불명확한 추가 동작은 반복하지 않는다. 같은 작업 자료·첨부·탭에서 이어한다.
- 오류검증 성공 알림을 확인하고 실제 입력 상태와 함께 기록한다. 중단 시 입력칸/표/버튼 구조를 자동 수집해 `기록 저장`에 포함한다. 비밀번호/입력값은 진단 목록에 넣지 않는다.

## 검증과 제한

- 로컬 Node 검사: 양식, 날짜, 코드, 성분 관계/배합비, 대표품목, 이전 값 단위, 중단 기록 복구.
- 실제 Chrome 확장에서 합성 UNI-PASS 화면을 사용한 전체 흐름: 2개 품목, 조회창, 표시사항 2행, 공정 2개, 주/부성분 3행, 원본 사진/PDF, 오류검증.
- 앱 다시 열기 및 pending 기록 복구, 성분 순번 재배치, 대상 신청서 변경 차단, 안내 문구 변경 차단을 검사했다. 전송 요청은 0회다.
- 기존 폴더/XLSX/사진 선택/작업 저장/실적 검색 검사도 통과했다.
- 이 테스트 화면은 매뉴얼·스크린샷 기반 합성 화면이다. 실제 UNI-PASS 신규 화면의 DOM을 캡처한 것은 아니다. 실제 업무 신고서의 신규 입력·저장·전송은 검증하지 않았다.
- 성분의 조건부 제품구분/품목유형, 혼합성분 및 일반 선택항목 전체 조합은 실제 화면에서 추가 확인이 필요하다. 농수산물·축산물·기구 등 다른 신고제품구분은 이번 신규 자동화 범위 밖이다.
- 실적 검색의 결과가 여러 페이지이거나 최신 날짜 동률이면 임의로 선택하지 않는다. 기존 복사 입력은 단일 품목이다.

공개 안정 버전은 v1.0.11을 유지한다. v1.1.0은 별도 테스트 설치 파일로 제공하며 최신 자동 업데이트로 배포하지 않는다. 이미 완료한 신고서를 다시 실행할 필요는 없다.
